# Tom's Jazz School

Uma página web moderna e responsiva desenvolvida para uma escola de música focada no ensino de jazz e instrumentos relacionados. O projeto apresenta uma interface limpa, estruturada em HTML5 semântico e estilizada com CSS.

---

## 🎨 Seções da Página

* **Cabeçalho (Header):** Contém o logotipo oficial da escola, menu de navegação rápido (Início, Cursos, Eventos, Contato) e um botão de chamada para ação (CTA) para inscrição.
* **Seção Principal (Hero Section):** Destaque visual principal com uma chamada impactante ("Crie algo impactante com música") acompanhada de imagem ilustrativa e botão para iniciar.
* **Cursos Oferecidos (Courses Section):** Grade de cartões interativos apresentando os principais cursos disponíveis:
  * Piano popular
  * Teoria musical
  * Sax alto
  * Bateria
* **Rodapé (Footer):** Seção institucional contendo informações da escola, links de navegação secundários e um formulário de inscrição para newsletter voltado para o recebimento de materiais gratuitos.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica do conteúdo.
* **CSS3:** Estilização, layout e responsividade.
* **Google Fonts:** Tipografia personalizada utilizando a fonte *Roboto*.
